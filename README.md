# Риелтор-Профи — Платформа для поиска жилья

> Современный веб-сервис для взаимодействия клиентов и риелторов.  
> Найти квартиру, подтвердить личность, общаться в чате — всё в одном месте.

---

## Описание

**Риелтор-Профи** — это одностраничное приложение (SPA), позволяющее:
- Риелторам размещать объявления о недвижимости
- Клиентам находить проверенных риелторов и обьявления при помощи удобного поиска
- Обмениваться сообщениями в реальном времени
- Подтверждать учётные записи по email

Проект реализован с нуля как full-stack решение с акцентом на безопасность, удобство и масштабируемость.

Frontend разработан мной, Backend при помощи QwenAI так как моя цель создать в первую очередь рабочее фронтенд приложение на react

---

## Технологии

| Слой | Технология |
|------|-----------|
| Фронтенд | React + TypeScript + Vite |
| Бэкенд | Node.js + Express |
| База данных | MongoDB (через Mongoose) |
| Авторизация | JWT в HttpOnly-куках |
| Подтверждение email | Nodemailer + Gmail App Password |

---

## Безопасность

- Пароли хешируются через `bcrypt`
- JWT токены передаются только в защищённых куках (`HttpOnly`, `SameSite=Lax`)
- Подтверждение email предотвращает регистрацию чужих почт
- CORS настроен строго для доверенных доменов

## База данных: почему MongoDB?

MongoDB выбрана на этапе разработки, потому что:
- Проста в освоении и быстра в старте
- Хранит данные в формате, близком к JSON
- Идеально подходит для прототипирования и гибких моделей
