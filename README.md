# 🏠 Риелтор-Профи — Платформа для поиска жилья

> Современный веб-сервис для взаимодействия клиентов и риелторов.  
> Найти квартиру, подтвердить личность, общаться в чате — всё в одном месте.

---

## 📌 Описание

**Риелтор-Профи** — это одностраничное приложение (SPA), позволяющее:
- Клиентам находить проверенных риелторов
- Риелторам размещать объявления о недвижимости
- Обмениваться сообщениями в реальном времени
- Подтверждать учётные записи по email

Проект реализован с нуля как full-stack решение с акцентом на безопасность, удобство и масштабируемость.

Frontend разработан мной, Backend преимущественно QwenAI так как моя цель создать в первую очередь рабочее фронтенд приложение на react

---

## 🛠 Технологии

| Слой | Технология |
|------|-----------|
| Фронтенд | React + Vite |
| Бэкенд | Node.js + Express |
| База данных | MongoDB (через Mongoose) |
| Авторизация | JWT в HttpOnly-куках |
| Подтверждение email | Nodemailer + Gmail App Password |
| Чат (в будущем) | Socket.IO |
| Деплой | Docker, Vercel / Render |

---

## 🔐 Безопасность

- Пароли хешируются через `bcrypt`
- JWT токены передаются только в защищённых куках (`HttpOnly`, `SameSite=Lax`)
- Подтверждение email предотвращает регистрацию чужих почт
- CORS настроен строго для доверенных доменов
- Перед продакшеном планируется переход на PostgreSQL

## 🚀 Запуск проекта

### 1. Установи зависимости

```bash
# В корне проекта
npm install

# Установи зависимости фронтенда
cd client && npm install

# Установи зависимости бэкенда
cd ../server && npm install
```

### 2. Настрой переменные окружения

Создай `.env` в папке `server/`:

```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/rieltorprofi
JWT_SECRET=секретный_пароль_длиннее_16_символов

EMAIL_USER=your_email@gmail.com
EMAIL_PASS=ваш_app_password_из_Gmail
```

> ⚠️ Не коммить `.env` в GitHub!

### 3. Запусти базу данных через Docker

```bash
docker run -d \
  --name mongodb-container \
  -p 27017:27017 \
  -v mongo-data:/data/db \
  --restart unless-stopped \
  mongo:6
```

### 4. Запусти оба сервера

```bash
# В корне проекта
npm run dev
```

→ Фронтенд: `http://localhost:5173`  
→ Бэкенд: `http://localhost:5000`

## 📂 База данных: почему MongoDB?

MongoDB выбрана на этапе разработки, потому что:
- Проста в освоении и быстра в старте
- Хранит данные в формате, близком к JSON
- Идеально подходит для прототипирования и гибких моделей

➡️ Перед выходом в продакшен будет рассмотрена возможность перехода на **PostgreSQL** для лучшей целостности данных, сложных запросов и связи между таблицами.
